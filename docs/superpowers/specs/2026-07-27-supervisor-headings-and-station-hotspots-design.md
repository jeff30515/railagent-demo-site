# 主管首頁標題與站點熱點設計

## 目標

補回主管首頁原 React 介面中的「站點熱點」長條表，並讓首頁及歷史頁都有清楚的主標題與小字說明。

## 首頁

- 主標題固定為「即時營運監控」。
- 主標題下方顯示：「掌握拾獲物品、旅客追蹤與各站點即時營運概況」。
- 保留既有即時 KPI、站務人力與原 React「站點熱點」長條表。
- 繼續隱藏「時段熱點」、「狀態佇列」、「優先佇列」與待辦 drill-down。

## 歷史

- 最上方顯示主標題「歷史服務品質分析」。
- 主標題下方顯示：「透過事件趨勢、使用次數與服務回饋檢視營運品質」。
- 主標題後保留既有四個分析區塊，不混入即時 KPI、站務人力或舊待辦內容。

## 實作邊界

- 只調整 `assets/supervisor-dashboard-enhancer.js`、其對應測試及必要快取版本。
- 站點熱點沿用 React 原有節點；增強腳本不得建立第二份熱點資料。
- 保留底部「首頁／歷史／帳戶」、圖示節點與 390px 無橫向溢位的行為。

## 驗收

1. 首頁顯示主標題、說明、KPI、站務人力與可見的站點熱點。
2. 首頁不顯示時段熱點、狀態佇列、優先佇列或舊待辦。
3. 歷史頁最上方顯示主標題與說明，並只顯示四個既有統計區塊。
4. 重複切換首頁／歷史／帳戶後，標題、說明、導覽圖示與頁面隔離均維持正確。
