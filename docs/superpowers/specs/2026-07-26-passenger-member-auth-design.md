# 旅客會員登入／加入會員頁面設計

## 目標

將旅客「我的」頁面從帳戶摘要改為會員入口，讓使用者可在同一頁切換登入與註冊表單；保留返回身分選擇的出口。

## 範圍

- 頁面標題改為「會員登入」。
- 提供「會員登入」與「加入會員」兩個可操作頁籤，預設為會員登入。
- 移除既有帳戶摘要與重設示範按鈕。
- 保留最下方「返回身分選擇」按鈕及其既有導頁行為。

## 表單

### 會員登入

- 帳號
- 密碼
- 記住帳號核取方塊
- 忘記密碼連結／按鈕
- 提示語：建議會員每三個月定期更換密碼，密碼規則為 8–12 字元，至少一個英文字與一個數字。

### 加入會員

- 證號
- 密碼
- 再次確認密碼
- 姓名
- 性別（男／女）
- 生日
- E-mail
- 手機
- 居住地

## 互動與視覺

- 使用既有卡片、主按鈕、次按鈕與標籤樣式；不新增外部依賴。
- 頁籤以 `role="tablist"`、`role="tab"` 和 `aria-pressed` 呈現目前選項，鍵盤可聚焦操作。
- 每個欄位使用既有標籤／輸入元件；密碼欄位採 `type="password"`，生日採 `type="date"`，性別採原生選單。
- 登入／註冊按鈕僅做本機 Demo 回饋，不串接真實驗證或保存個人資料。
- 窄螢幕下欄位維持單欄排列，避免橫向捲動。

## 驗證

- 加載頁面後預設顯示會員登入欄位與提示語。
- 點選加入會員後，登入內容隱藏並顯示九個註冊欄位。
- 再切回會員登入後，登入內容恢復。
- 返回身分選擇按鈕仍可正常回到入口。
