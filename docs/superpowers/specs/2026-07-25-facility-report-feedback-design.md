# 服務設施回報：現場問題與送出回覆

## 目標

讓旅客在服務設施回報流程中描述現場問題，並在送出成功後立即取得明確的感謝回覆。

## 使用流程

1. 旅客開啟「服務設施回報」。
2. 旅客在「請描述現場問題」多行欄位輸入問題。
3. 若欄位為空即送出，頁面顯示必填提示且保留在表單。
4. 若內容有效，系統送出回報，改顯示「感謝您的回報，我們已通知相關人員處理。」

## 範圍與限制

- 保留既有站點與設施選擇流程。
- 本次不新增後端儲存、案件追蹤或通知串接。
- 文字欄位為必填，以避免沒有問題內容的回報。

## 驗證準則

- 可輸入並編輯現場問題。
- 空白內容不能完成送出，且提示清楚說明原因。
- 有內容送出後可見指定感謝訊息。
