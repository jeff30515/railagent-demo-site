# RailAgent 唯一旅客功能版本設計

## 目標

RailAgent 公開網站只能呈現一套旅客功能。使用者不論開啟首頁裸網址，或使用帶有 `apiBaseUrl` 的網址，都必須看到相同的完整繁體中文旅客功能，不得再回到只有「快速求助／更多服務」的舊畫面。

## 唯一版本行為

- `apiBaseUrl` 預設為 `http://127.0.0.1:7071`。
- 網址有合法 `apiBaseUrl` 時使用該值；沒有參數時使用預設值。
- 網址參數無效時仍保留完整功能畫面，操作本機功能時顯示明確的連線錯誤。
- 首頁固定顯示：
  - 友善轉乘協助
  - 遺失物協尋
  - 服務設施回報
  - 問 RailAgent
- 首頁不顯示「快速求助」與「更多服務」。
- 友善轉乘、遺失物、設施回報、案件、會員功能以提交 `7b5c47f` 的完成版本為行為基準。

## 實作邊界

目前靜態網站只保留編譯後的 React bundle，沒有可維護的 React 原始碼。因此本次不修改壓縮 bundle，也不直接刪除或插入 React 管理的節點。

唯一版本由既有、已驗證可正常切頁的功能增強腳本負責：

1. 移除「缺少 `apiBaseUrl` 就提前結束」的分支。
2. 將缺省 API 位址設為 `http://127.0.0.1:7071`。
3. 保留原本安全的畫面增強方式，不引入定時刪除、MutationObserver 直接破壞 React 子節點或重複注入。
4. 不重新引入先前造成白屏的多語 DOM 覆寫腳本。

## 錯誤處理

- 本機 API 未啟動：完整畫面仍存在；搜尋、聊天或路線功能顯示無法連線訊息。
- `apiBaseUrl` 格式錯誤：退回預設本機 API 位址。
- API 回應錯誤：保留表單輸入並顯示錯誤，不切換成舊畫面。

## 驗收條件

### 裸網址

開啟 `https://jeff30515.github.io/railagent-demo-site/`：

- 首頁有四個完整服務入口。
- 沒有「快速求助」與「更多服務」。
- 三個服務內頁皆可開啟及返回，沒有白屏。

### 帶參數網址

開啟 `https://jeff30515.github.io/railagent-demo-site/?apiBaseUrl=http://127.0.0.1:7071`：

- 與裸網址呈現相同首頁和內頁。
- 本機 API 啟動時，搜尋、聊天和轉乘建議可呼叫本機服務。

### 回歸驗證

- 前端測試覆蓋有參數與無參數初始化。
- API 測試與 TypeScript 型別檢查通過。
- GitHub Pages 部署後實際點擊友善轉乘、遺失物、設施回報、案件和會員頁。
- 驗證過程不得靠 CSS 新增另一套頁面，也不得直接移除 React 管理節點。

## 非目標

- 本次不重新進行九種語言同步。
- 本次不重建缺失的 React 原始專案。
- 本次不修改角色入口圖片或整體視覺設計。
