# 九語旅客功能同步設計

## 目標

RailAgent 的九種語言必須共用同一套旅客功能，語言切換只能改變文字，不得切回舊首頁或舊內頁。

支援語言：

- 繁體中文 `zh-TW`
- 臺語 `nan`
- 客語 `hak`
- 英文 `en`
- 日文 `ja`
- 韓文 `ko`
- 越南文 `vi`
- 印尼文 `id`
- 泰文 `th`

本次同步範圍：

- 友善轉乘協助
- 遺失物協尋
- 服務設施回報
- 案件

首頁與內頁圖片維持原圖，不翻譯、不替換。

## 已確認根因

目前完成版功能由 `assets/lost-found-local-api.js` 與其他增強程式安裝，但部分頁面辨識依賴繁中文字串：

- 首頁用繁中的「服務設施回報」尋找插入位置。
- 友善轉乘用繁中的「友善轉乘協助」尋找頁面。
- 遺失物搜尋按鈕只列出繁中與英文文字。
- 黃色資料來源說明只辨識繁中與英文句子。
- 案件清理由繁中特定內容或標題辨識。

因此繁中能取得完成版功能，其他語言則部分或全部保留 React 內建舊功能。臺語與客語的黃色資料來源文案不同，也不會被現有條件移除。

這不是語言套件或下載失敗；九種語言文案已包含在前端檔案中，問題位於功能增強層的頁面辨識方式。

## 架構

### 單一功能執行層

保留一個正式旅客功能執行層。不得重新載入下列舊覆寫：

- `passenger-i18n.js`
- `gate-i18n.js`
- `gate-i18n.css`

所有語言共用相同的事件處理、API 端點、追蹤資料結構與頁面流程。

### 語言解析

以 `document.documentElement.lang` 作為旅客頁目前語言來源，正規化為九種語言代碼。無法辨識時回退繁體中文。

功能程式提供九語文案表，只包含它新增或改寫的文字。React 已有文案與入口圖片不重做。

### 穩定頁面辨識

不得再用畫面上的單一語言文字判斷頁面。

- 遺失物：使用 `[data-service-page="lost-item"]`。
- 服務設施回報：使用 `[data-service-page="facility-report"]`。
- 案件：使用 `[aria-label="public own case list"]`。
- 友善轉乘：使用目前語言的既有標題集合加上頁面結構驗證；不得只比對繁中文字。
- 首頁服務：使用服務按鈕的既有結構與九語標題集合辨識。

### 首頁

九種語言都必須顯示：

- 友善轉乘
- 遺失物
- 服務設施回報
- 問 RailAgent

九種語言都不得顯示：

- 快速求助
- 更多服務

「問 RailAgent」與聊天視窗使用目前語言文案，但共用相同本機 API 與事件處理。

### 友善轉乘

九種語言都使用完成版流程：

- 轉乘協助按鈕
- 目前位置
- 目的地
- 取得轉乘建議
- 呼叫站務協助
- 本機 API 錯誤提示

所有控制項文字與提示依目前語言顯示，功能與繁中一致。

### 遺失物

九種語言都保留七個搜尋欄位並由同一個本機 API 搜尋。

搜尋攔截改由遺失物頁面結構與按鈕位置判斷，不再依賴按鈕文字。

黃色資料來源區塊改由以下結構辨識後移除：

- 位於 `[data-service-page="lost-item"]` 內。
- 包含臺鐵遺失物來源連結或資料來源提示容器。

因此繁中、臺語、客語及其他語言使用不同句子時仍會移除。

搜尋結果、追蹤按鈕、狀態與聯絡資訊依目前語言顯示。追蹤資料格式維持一致，使切換語言後仍能查看同一案件。

### 服務設施回報

九種語言都使用相同表單：

- 問題描述文字區域
- 必填驗證
- 送出按鈕
- 成功感謝訊息

表單文字依目前語言顯示。設施回報頁不得插入「問 RailAgent」卡片；該卡片只能出現在首頁。

### 案件

九種語言都使用相同案件行為：

- 移除舊的固定黑色背包示範案件。
- 顯示使用者實際追蹤的遺失物。
- 可取消追蹤。
- 顯示服務回饋表單。
- 移除舊的本機事件目錄說明。

固定示範案件改由穩定事件編號或結構辨識，不依賴案件標題語言。

案件狀態、聯絡資訊、回饋欄位與按鈕使用目前語言文案。

## 錯誤處理

- 本機 API 未啟動時，所有頁面與表單仍需完整顯示。
- API 動作失敗時在目前頁面顯示該語言的連線錯誤，不得白屏或退回舊功能。
- 未知語言代碼回退繁體中文功能文案。
- 無法找到預期頁面結構時不修改其他 React 頁面，也不得拋出未處理錯誤。

## 測試

### 自動化回歸測試

- 九種語言代碼都存在於功能文案表。
- 功能頁辨識使用穩定屬性，不以繁中文字作唯一條件。
- 遺失物黃色來源區塊以結構移除。
- 遺失物搜尋事件對九種語言使用同一處理器。
- 設施回報表單具九語文案且不插入首頁聊天卡。
- 案件固定示範資料由穩定識別移除。
- `index.html` 不載入舊多語覆寫檔。

### 正式站驗證

部署後依序驗證九種語言：

1. 首頁只有三項服務與問 RailAgent。
2. 友善轉乘顯示完整轉乘與站務協助功能。
3. 遺失物顯示七欄搜尋，且沒有黃色資料來源區塊。
4. 服務設施回報顯示描述表單，且沒有額外問 RailAgent 卡片。
5. 案件顯示回饋與追蹤功能，不顯示固定黑色背包示範案件。
6. 所有頁面皆不得白屏。

## 不在範圍內

- 不翻譯或重製入口角色圖片。
- 不更改站務／主管流程。
- 不新增線上翻譯服務或語言下載依賴。
- 不重新設計入口語言按鈕排列。
- 不改變本機 API 的資料來源或 Ollama 模型。
